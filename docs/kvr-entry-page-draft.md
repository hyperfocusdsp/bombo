## Tagline (one line)

Classified ordnance for the kick. Seven stages of detonation.

## Short description (1–2 sentences)

A free kick designer with a reorderable FX rack. A synth sub voice and a sample
slot feed a shared detonation path through drive, a tempo-synced delay, a
multi-algorithm reverb, a resonant filter, and a sidechain ducker. Drag the
stages into any order and the signal path rebuilds in real time.

## Long description

A kick designer issued as classified ordnance. A synth sub voice and a sample
slot, a drive stage, a tempo-synced delay, a multi-algorithm reverb, a resonant
filter, and a sidechain ducker, racked vertically against a stubby ordnance chassis. The rack is yours:
drag the stages into any order and the signal path rebuilds in real time. Tap a
header to mute a stage. Loop on, beat lined up, hit DICE when the day is short
and a new round rolls out of the warhead bay.

Free. VST3, AU, CLAP, standalone. Windows, macOS, Linux. Single-shot or looped.
Quiet enough for headphones, loud enough for the wall.

The default finish is a weathered, photoreal ordnance chassis with a green
phosphor scope. It isn't the only skin in the unit; flat and blueprint finishes
are in there too, switchable at runtime with no reload.

The Windows binary isn't codesigned yet (the EV certificate is deferred until
paid plugins ship), so SmartScreen warns on first launch: "More info" → "Run
anyway". The macOS build is signed and notarized; Linux is unaffected.

## Features (bullet list)

- Two-voice kick engine: a synth sub plus a sample slot, crossfaded
- Reorderable FX rack: drive, tempo-synced delay, multi-algorithm reverb, resonant filter, sidechain ducker. Drag stages into any order and the signal path rebuilds in real time
- Per-section mute by tapping the section header
- Loop playback with a DICE control for one-roll variations
- Ten factory rounds, from a clean sub to splintered hardtechno (Hardtech, Reverze, Juicy, Chunky, Crusher, Hammer, Hardkick, Horror, Pew, Superwet)
- Photoreal, weathered ordnance finish with a green phosphor scope, plus more runtime-switchable skins, flat blueprint mode included
- One-shot bounce to WAV or AIFF from the BNC control, without leaving the chassis
- Single-shot or looped playback, host-synced in a DAW

## System requirements

- Windows x86_64: VST3 / CLAP / standalone
- macOS (Apple Silicon + Intel, universal): VST3 / AU / CLAP / standalone
- Linux x86_64: VST3 / CLAP / standalone
- Loads in Reaper, Bitwig, Live, Cubase, Studio One, FL, Renoise, Ardour (VST3/CLAP), and Logic Pro (AU)
